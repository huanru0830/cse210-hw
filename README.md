# cse210-student-template
This is the starter code for students in CSE 210.

This repository contains the starter code for many different projects. They are arranged as follows:

* `sandbox` - An empty project that you can use to play around with any concepts you like.
* `csharp-prep` - Starter projects for each of the C# Prep assignments.
* `prepare` - Starter projects for each of the preparation Learning Activities.
* `prove` - Starter projects for each of the prove Developer projects.
* `final` - Starter projects for final project.


# Pet Simulation System 🐶

## Overview
This project is a simple pet simulation system built using C#. The goal of the program is to simulate taking care of a virtual pet by managing its needs such as hunger, mood, and resources.

## Features
- Feed the pet using food items
- Manage inventory (Food, Toys, etc.)
- Track pet status (Hunger, Mood)
- Basic money system
- Time progression system
- Simple interaction through console

## Project Structure
- Pet / Dog: Represents the pet
- Food / Toy / Item: Objects the pet can use
- Inventory: Stores items
- HungerSystem / MoodSystem: Manage pet needs
- MoneySystem: Handles currency
- TimeManager: Controls time progression
- GameState: Stores overall game state
- SaveManager: Handles saving (basic setup)
- Shop: Placeholder for buying items
- Program: Entry point of the application
